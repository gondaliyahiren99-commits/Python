1.What are constraints in SQL? List and explain the different types of constraint.
SQL me constant rules he jo table ke apply pr kuch restriction lagata he.jo pure table me data add karene pr kuch limit rahegi.
1) NOT NULL : Jis collum me NOT NULL likha he us collume ko hum empty nahi chhod sakte. agar empty chhoa to eror show karega.
2) UNIQUE : Jis collum ko unique kiya hua he wo duplicate value allowed nahi karega.agar duplicate dala to error dega.
3) PRIMERY KEY : Ye har table pe ek collum ko de sakte he.agar koi collum ko primery key di he to wo unique value or Not Null value hi accept kar skta he.
4) DEFAULT : Koi collum ko default kiya hua he agar value insert ke time jab nalue add na ki ho tab wo automaticaly default me jo value add kiya he wo store ho jayegi.
5) CHECK : koi collum ko check condition di he to value insert ke time wo dekhega ki condition ke hisab se value di gayi he to insert hogi nahi to error ayegi.
6) AUTO INCREMENT : isse collum me insert ke time numeric value dene kei jaroorat nahi wo automaticaly har next value deta jayega.
7) FOREIGN KEY : Ek dable ko dusre table se combie karne ke liye use hota he.

How do PRIMARY KEY and FOREIGN KEY constraints differ?
PRIMERY KEY :  Ye per table pe ek collum ko de sakte he.agar koi collum ko primery key di he to wo unique value or Not Null value hi accept kar skta he.
FOREIGN KEY : ye ek table ki primery key ko dusre table ki jo foreign key banayo usko combine karke table ko jodne ke liye use hota he.

What is the role of NOT NULL and UNIQUE constraints?
Jis collum me NOT NULL likha he us collume ko hum empty nahi chhod sakte. agar empty chhoa to eror show karega.
Jis collum ko unique kiya hua he wo duplicate value allowed nahi karega.agar duplicate dala to error dega. agar unique me value na de to wo null ho sakti he.
